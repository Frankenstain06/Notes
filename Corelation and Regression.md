# Corelation and Regression

**Regression :**

```html
if r = 0 => no regression and no correlation
if r > 0 => positive regression
if r < 0 => negative regression
if 0.5 < r < 1 => high correlation
if -0.5 > r > -1 => high correlation
if r < 1 => imperfect regression
if 0 < r < 0.5 => low correlation
if 0 > r > -0.5 => low correlation
if r = 1 => perfect positive correlation
if r = -1 => perfect negative correlation
```
